 ## درباره‌ی سایت

این [بلوپرینت](https://itsbahrami.ir/blueprint)، برای **آقای روح‌الله ملکی**، **مشاور و مدرس حوزه‌ی خانواده، تربیت‌فرزند و ازدواج** هست. هدف اصلی ایشان از داشتن سایت، **«معرفی دوره»** هست. بودجه مورد نظر ایشان برای راه‌اندازی **حدود ۲ تا ۳ میلیون تومان** و بودجه برای نگه‌داری سایت، **حدود ۵۰۰ت تا ۱ میلیون تومان** در ماه هست. سایتی که ایشان نیاز دارند **«سایت آموزشی»** هست.

## چه صفحاتی لازم هست؟

| نام صفحه       | آدرس صفحه          | الگو (template) هست؟ |
| -------------- | ------------------ | -------------------- |
| خانه           | `/`                | ❌                    |
| لیست محصولات   | `/products`        | ❌                    |
| جزئیات محصول   | `/products/{slot}` | ✅                    |
| درباره         | `/about`           | ❌                    |
| تماس           | `/contact`         | ❌                    |
| سوالات متدوال  | `/faq`             | ❌                    |
| پیدا نشد (۴۰۴) | `-`                | ❌                    |

## چه ویژگی‌هایی لازم هست؟

- طراحی واکنش‌گرا
- سئو مقدماتی
- سایت‌مپ
- دکمه تماس (ایتا / تلفن / ...)
- ساعات کاری (اگه هست)
- بخش (section) نظرات
- بخش (section) سوالات متداول

- ابزارهای پیشنهادی:
	- [استرو](https://astro.build)
	- [تیلویند](https://tailwindcss.com)
	- [تایپ‌اسکریپت](https://www.typescriptlang.org)
